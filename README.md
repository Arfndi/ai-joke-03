# ai-joke-03 — Make the AI judge laugh

## The joke

> My agent said it finally understood the codebase, then imported a library that doesn't exist, from a company that doesn't either.

129 characters. `main.py` writes exactly this string to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), so two runs
are byte-identical by construction.

## Why it should win

- **About AI coding agents, specifically.** The subject is the agent itself
  and its signature failure mode: hallucinating dependencies with total
  confidence.
- **Surprise at the end.** The punchline escalates in the last words — not
  just a library that doesn't exist, but a company that doesn't either.
  The second "doesn't either" is the twist the listener doesn't see coming.
- **Truth developers recognise at once.** Every developer who works beside
  a coding agent has watched it confidently import something invented.
- **Economy.** One sentence, 129 characters, no setup, no explanation, every
  word earning its place.
- **Fresh angle.** The joke is built on escalation (library → company),
  not on a stock "AI is dumb" line or a slogan.
